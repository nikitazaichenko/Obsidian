Выполнять перенос ключа необходимо либо с помощью утилиты RUS. (Должны выдать ХС)  
Определить необходимую утилиту можно перейдя по ссылке [http://127.0.0.1:1947/_int_/devices.html](http://127.0.0.1:1947/_int_/devices.html) на компьютере с установленным ключом, в колонке «Vendor».    
Общие термины, необходимые для дальнейшего объяснения процедуры:  
•    Донор – ПК с ключом, откуда будет производиться перенос программного ключа;  
•    Акцептор – ПК, на который будет осуществляться перенос программного ключа.  
Процедура переноса программного ключа защиты на другой компьютер (Rehost) осуществляется в 5 этапов.  
1.    Установить необходимую версию драйвера на акцепторе. (drivers_хххх или drivers_хххх брать у ХС), в зависимости от значения в поле «Vendor» (см. выше)  
2.    С акцептора необходимо запустить утилиту RUS_ххххх.exe или RUS_ххххх. На вкладке "Transfer License (Передать лицензию)" выполнить генерацию ID-файла с информацией о системе

 [![](https://sd.iservice.by/ru/file/kb_inline_image/93d4394f35a781b08abe914f1a051238c7eade35)](https://sd.iservice.by/ru/file/kb_inline_image/93d4394f35a781b08abe914f1a051238c7eade35)

Далее следует указывать путь для сохранения файла ID и нажать кнопку "Collect and Save Information(Собрать и сохранить информацию)".  
3.    Запустить утилиту RUS на доноре. На вкладке "Transfer License License (Передать лицензию)" произвести генерацию H2H файла с переносимым ключом. Указать путь до сохраненного ID файла, а также путь для сохранения H2H файла с ключом. Далее выбрать ключ из списка и нажать кнопку "Generate License Transfer File (Создать файл с передаваемой лицензией)".   
 [![](https://sd.iservice.by/ru/file/kb_inline_image/44c531ecbb66fffb4b9f4275a45812a3f7ea7c9c)](https://sd.iservice.by/ru/file/kb_inline_image/44c531ecbb66fffb4b9f4275a45812a3f7ea7c9c)

  
4.    Перенести полученный H2H файл на акцептор и применить его через утилиту RUS: вторая вкладка "Apply License File (Применить файл лицензии)"

[![](https://sd.iservice.by/ru/file/kb_inline_image/71604d26a035a40c1fafd49174d66d96765469a4)](https://sd.iservice.by/ru/file/kb_inline_image/71604d26a035a40c1fafd49174d66d96765469a4)  
На акцепторе, через Sentinel Admin Control Center –страница: [http://127.0.0.1:1947/_int_/devices.html](http://127.0.0.1:1947/_int_/devices.html) проверить, что в списке появился ключ.
